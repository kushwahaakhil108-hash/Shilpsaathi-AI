# Shilpsaathi-AI
"ShilpSaathi is an AI-powered web application built with Base44, designed to be a digital companion for India's artisan and craft community. The name combines 'Shilp' (craft) and 'Saathi' (companion), reflecting its mission to bring modern AI tools to traditional handcrafted work. Built on the Base44 no-code platform, ShilpSaathi offers a clean, accessible web interface where users can explore AI-assisted workflows tailored to artisans, craftspeople, and small creative businesses. It represents an effort to bridge India's rich heritage of handmade goods with practical, easy-to-use technology. A live demo is available at craft-saathi-flow.base44.app.
